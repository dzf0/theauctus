# Design MD Brand References

74 curated DESIGN.md files from real brand design systems. Each file documents that brand's typography, colors, spacing, component patterns, and design principles.

## How to use

1. **Find the brand**: Pick the closest brand match from the table below.
2. **Read the reference**: Load `docs/design-md/<brand>/DESIGN.md` for the full design system.
3. **Apply tokens**: Extract colors, fonts, spacing, radii, and component patterns from the reference.
4. **Adapt, don't copy**: Merge the brand's design language into the existing project structure.
